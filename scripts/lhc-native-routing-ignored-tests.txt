# Reviewed native-routing ignore allowlist (LIM-142).
#
# Codex-LHC routes every compact entry point through
# `compact_lhc::run_strict_lhc_compact`. Upstream's native TokenBudget /
# remote / local compaction implementation is retained for upstream parity,
# but the upstream *integration* tests whose owned assertion is that a normal
# entry point issues native local, remote `/responses/compact`, or TokenBudget
# compaction have a false premise here. Those tests — and only those — carry
#
#     #[ignore = "codex-lhc LIM-142 strict-lhc-routing: <reason>"]
#
# and are listed below. `scripts/check-lhc-compact-ignores.sh` fails on any
# drift between this file and the tree, so the exclusion cannot grow silently.
#
# Classification (source-level, not failure membership):
#   1. Strict-LHC supported behavior stays ACTIVE. Where an old native fixture
#      still named a supported invariant (hooks, pending input, resume/fork,
#      current-time, window, budgets), an active LHC test owns that invariant
#      and the old test is listed only because its remaining premise is the
#      native compact request itself.
#   2. Route-independent native helper/unit coverage stays ACTIVE
#      (`compact::tests`, `compact_remote` metadata/v2 unit tests, skip-path
#      pre-sampling tests, already-ported suite routing proofs).
#   3. False-premise native-routing integration coverage — this list.
#
# Adding a line here is a reviewed change: it must be a test whose owned
# assertion is native routing, never a way to silence a real regression.
#
