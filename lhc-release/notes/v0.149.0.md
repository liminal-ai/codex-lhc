# Codex + LHC v0.149.0

This release packages stable Codex 0.149.0 with the exact public LHC SDK
`9d4d18247942f35b356f28bdc4288f0e631a6da9`.

Bounded metadata-first Smart Compact remains the default. Set
`LHC_COMPACT_ALGORITHM=legacy` to select the explicit legacy rollback path.

The five native archives use the canonical Codex package layout. Every package
contains Codex, Code Mode host, bundled ripgrep, canonical metadata, and LHC
provenance. Linux packages also contain bwrap and patched zsh; Windows packages
contain the command runner and sandbox setup helpers.
