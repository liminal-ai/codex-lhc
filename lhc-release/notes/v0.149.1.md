# Codex + LHC v0.149.1

This release packages stable Codex 0.149.1 with the exact public LHC SDK
`713b38d9eb8497b48023977cec2d84df9568bd58`.

The bounded selector remains the default. Set `LHC_COMPACT_ALGORITHM=legacy` to
select the legacy eager selector.

LHC thread schema advances from 11 to 12. Opening a schema-v11 thread with
v0.149.1 migrates it to schema 12; downgrade to v0.149.0 is unsupported.

The five native archives use the canonical Codex package layout. Every package
contains Codex, Code Mode host, bundled ripgrep, canonical metadata, and LHC
provenance. Linux packages also contain bwrap and patched zsh; Windows packages
contain the command runner and sandbox setup helpers.

## Accepted evidence

- Deterministic burn-in: PASS.
- Headed GNOME validation: PASS.
- Provider-pressure crossing: **not established.** The model-emitted code-mode
  `exec` calls requested `max_output_tokens: 2000`. Those requested limits
  truncated the tool results before canonical context, so the final exact
  attempt reached 333,651 tokens and stayed below the unchanged 350K compact
  trigger. The trigger was therefore never crossed under genuine provider
  pressure. This was not a product defect and was not rerun; the crossing is
  closed unestablished, and this release makes no claim that it passed.
