# Codex + LHC v0.149.2

This release packages Codex 0.149.2 with the exact accepted LHC SDK
`13573a16759582ec77efb00b2c8fe11cf20c43ba`.

The bounded selector remains the default. Set `LHC_COMPACT_ALGORITHM=legacy` to
select the legacy eager selector.

LHC thread schema remains 12. This release introduces no migration; the
existing schema-11-to-12 boundary and unsupported downgrade to v0.149.0 remain
unchanged.

The five native archives retain the canonical Codex package layout. Every
package contains Codex, Code Mode host, bundled ripgrep, canonical metadata,
and LHC provenance. Linux packages also contain bwrap and patched zsh; Windows
packages contain the command runner and sandbox setup helpers.

## Accepted evidence

- The production Codex integration regression passes through a split turn,
  closes it, starts a genuine small next turn, preserves the prior nonempty
  Full suffix exactly once before the new prompt, and later settles the old
  turn before the newer active turn becomes the sole split turn.
- Provider-pressure crossing remains **not established**. No new genuine
  provider-pressure crossing was run or accepted for this release, so this
  release makes no claim that one passed.
