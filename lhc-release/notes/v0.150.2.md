# Codex + LHC v0.150.2

This release packages Codex-LHC 0.150.2, based on upstream Codex annotated
tag `rust-v0.150.1` (tag object `0eb410ad0dd161ea323b05452f978de01cd63430`,
peeled commit `90854393966b21e9ebfd21b122334eb09a20c93d`), with the exact
certified LHC SDK pin `5207952b0d6d5dadb95f810c75a18e0867da6b72` (LIM-133
bounded, non-copying shared opens and frontier/key-projection APIs).

Candidate source integrates, at exact identities: the LIM-132 upstream-0.150.1
merge base, the LIM-133 shared SDK pin, the LIM-134 PreTurn
readiness/prompt-preservation/lifecycle/exec-truth repair, and the LIM-135
bounded startup and reconciliation scans, plus the F7 exec resume-test
manifest (12 tests disabled with recorded reasons; harness artifact, prod
unaffected).

Behavioral highlights over 0.150.1:

- A resumed turn requiring strict PreTurn/Standalone LHC compact waits
  (bounded, cancellation-aware) for capture readiness instead of failing on a
  still-opening capture; hard compact failures surface truthfully instead of
  being laundered into empty successes.
- A completed turn with a nonblank prompt and no agent message is reported
  as failed by `codex exec` (human and JSONL paths) with a nonzero exit.
- Exactly one terminal lifecycle contributor (stop, abort, or error) fires
  per turn on task-level terminals.
- Capture startup and normal compact/reconcile paths use constant-row or
  caller-bounded LHC projections; no full-history scans or payload parses on
  normal startup.

LHC thread schema is unchanged. This release introduces no migration.

The five native archives retain the canonical Codex package layout.
