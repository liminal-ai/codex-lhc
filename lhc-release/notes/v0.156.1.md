# Codex + LHC v0.156.1

This release packages Codex-LHC 0.156.1 on upstream Codex 0.156.1
(`rust-v0.156.1`, peeled commit `b412ff32c4`). LHC thread schema remains 13;
opening an existing thread does not migrate it.

## What changed for users

- **Upstream 0.156.1.** This cut includes the upstream 0.156.1 Codex changes
  on top of the previous LHC release.
- **Context-window override.** A custom or operator-set model context window
  is kept when a turn is rebuilt, instead of being replaced by the default
  catalog window.
- **Guardian after compaction.** After a compact, Guardian review keeps later
  conversation in order. New work after a fold is not dropped, and overlapping
  user messages are not duplicated.
- **Unfinished work at close.** If a thread is closed or Codex exits while
  summary work is still running, that work is handed back so the next session
  on the same thread can continue from it.
- **Rewind.** Rewind is refused on LHC threads, with the message
  `Rewinding is not yet supported.`

## Known limitations

- Threads rewound under 0.155.1 or earlier can surface rewound turns via
  retrieval and after compaction. Native rewind never removed those turns from
  the LHC record, and this release does not rewrite them away.
- Editing a previous prompt (Esc, Esc) after a compaction says the prompt was
  not found. Rewinding stays unsupported on LHC threads either way.
- Quitting Codex or pressing Ctrl-C while a background summary is starting can
  leave that summary failed. That stretch of the conversation then shows as an
  excerpt instead of a summary.
- Background work that finishes after a compaction logs "unknown turn"
  warnings. The results still arrive.

## Qualification

- The fix for subagent replies after a compaction (a rebuilt user message
  carried the subagent reply's own id and the provider refused every later
  request) was reproduced on the pre-fix candidate (workflow run 36069745127,
  source `4745976fca`) with a real subagent, a manual compact, a kill and a
  reopen, and by a unit test that fails on that source. The fixed build is
  qualified on the exact promoted commit with the same live sequence.

## Packages

The five native archives (Linux x86-64/ARM64, Windows x86-64/ARM64, Apple
Silicon macOS) keep the canonical Codex package layout. Every package contains
Codex, Code Mode host, bundled ripgrep, canonical metadata, and LHC
provenance. Linux packages also contain bwrap and patched zsh; Windows
packages contain the command runner and sandbox setup helpers.
